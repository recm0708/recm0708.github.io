Privacidad y almacenamiento

Qué guarda la versión actual del sitio, qué servicios externos intervienen y cómo se gestionarán futuras tecnologías de seguimiento.

Última actualización: 27 de septiembre de 2026

1. Responsable

Rubén Enrique Cañizares Miranda administra el contenido y mantenimiento de este sitio. Para consultas de privacidad puede utilizarse ruben.canizares@outlook.com.

2. Estado actual de cookies

En la versión publicada a la fecha indicada, el código propio del sitio no crea cookies de analítica, publicidad ni seguimiento y no existe una plataforma de analítica integrada. Por ello no se muestra un banner de “Aceptar todas las cookies” que pudiera resultar engañoso.

3. Almacenamiento local

El sitio utiliza localStorage para preferencias funcionales:

  • recm0708-theme: recuerda el tema cuando el visitante lo cambia.
  • recm0708-lang: recuerda el idioma cuando el visitante lo cambia en páginas con selector ES/EN.
  • recm0708-legal-notice-v1: recuerda que el visitante reconoció el aviso inicial.

La versión actual evita guardar automáticamente tema e idioma en la primera carga si el visitante no ha cambiado esas preferencias.

4. Eliminación de preferencias

Estos datos pueden borrarse desde las opciones de privacidad o almacenamiento del navegador. Al eliminarlos se restauran preferencias predeterminadas y el aviso inicial puede mostrarse nuevamente.

5. Hosting y recursos externos

El sitio se publica mediante GitHub Pages y solicita recursos externos de Google Fonts y Font Awesome/CDNJS. Al conectarse a esos proveedores, el navegador puede transmitir datos técnicos habituales necesarios para entregar el recurso, como dirección IP y agente de usuario, de acuerdo con las políticas de cada proveedor.

Para mostrar en el footer la fecha y hora de la última actualización, el navegador consulta la API pública de GitHub para obtener la fecha del commit más reciente de la rama main. Esta consulta no se utiliza para crear perfiles, analítica ni publicidad.

6. Enlaces externos

GitHub, LinkedIn y demás servicios enlazados administran sus propias plataformas. Al visitarlos se aplican sus políticas y condiciones; este sitio no controla sus prácticas.

7. Formularios, cuentas y pagos

La versión actual no incluye cuentas de usuario, pagos, perfiles privados ni formularios propios que almacenen información personal en una base de datos del sitio. El contacto profesional se realiza mediante enlaces externos o correo electrónico.

8. Analítica, publicidad y futuras cookies

Si en el futuro se incorporan analítica, publicidad, contenido embebido con rastreo u otras tecnologías no esenciales, esta política se actualizará antes de activarlas y se implementará el mecanismo de consentimiento que corresponda, con una forma clara de rechazar tecnologías opcionales cuando sea aplicable.

9. Marco de protección de datos

El sitio se administra desde Panamá y toma como referencia el régimen panameño de protección de datos personales, incluida la Ley 81 de 2019 y su reglamentación mediante el Decreto Ejecutivo 285 de 2021, además de otras obligaciones que puedan resultar aplicables según futuros tratamientos.

10. Cambios

Esta política puede actualizarse cuando cambien funciones, proveedores, almacenamiento o mecanismos de contacto. La fecha de última actualización permanecerá visible.

No se afirma cumplimiento jurídico absoluto para todas las jurisdicciones. Si en el futuro existe tratamiento significativo de datos, comercio electrónico, cuentas, publicidad o analítica avanzada, esta política deberá revisarse nuevamente.

Privacy & storage

What the current site stores, which external services are involved and how future tracking technologies will be handled.

Last updated: September 27, 2026

1. Site operator

Rubén Enrique Cañizares Miranda manages the content and maintenance of this site. Privacy-related questions may be sent to ruben.canizares@outlook.com.

2. Current cookie status

As of the date shown above, the site's own code does not create analytics, advertising or tracking cookies and no site analytics platform is integrated. For that reason, the site does not display a misleading “Accept all cookies” banner.

3. Local storage

The site uses localStorage for functional preferences:

  • recm0708-theme: remembers the theme after the visitor changes it.
  • recm0708-lang: remembers language after the visitor changes it on pages with an ES/EN selector.
  • recm0708-legal-notice-v1: remembers acknowledgement of the initial site notice.

The current version avoids automatically storing theme or language on first load unless the visitor changes those preferences.

4. Deleting preferences

These values can be removed through the browser's privacy or storage settings. Removing them restores defaults and may cause the first-visit notice to appear again.

5. Hosting and external resources

The site is published through GitHub Pages and requests external resources from Google Fonts and Font Awesome/CDNJS. When connecting to those providers, the browser may transmit standard technical information needed to deliver the resource, such as IP address and user agent, subject to each provider's policies.

To display the latest update date and time in the footer, the browser queries the GitHub public API for the most recent commit date on the main branch. This request is not used for profiling, analytics or advertising.

6. External links

GitHub, LinkedIn and other linked services manage their own platforms. Their own policies and terms apply when visitors use them; this site does not control those practices.

7. Forms, accounts and payments

The current version does not provide user accounts, payments, private profiles or first-party forms that store personal information in a site database. Professional contact is handled through external links or email.

8. Analytics, advertising and future cookies

If analytics, advertising, tracking embeds or other non-essential technologies are added later, this policy will be updated before activation and an appropriate consent mechanism will be implemented, including a clear way to refuse optional technologies where applicable.

9. Data-protection context

The site is managed from Panama and takes the Panamanian personal-data framework into account, including Law 81 of 2019 and its implementing Executive Decree 285 of 2021, together with additional obligations that may apply to future processing.

10. Changes

This policy may be updated when features, providers, storage or contact mechanisms change. The latest update date will remain visible.

This policy does not claim absolute legal compliance for every jurisdiction. If the site later introduces significant personal-data processing, e-commerce, accounts, advertising or advanced analytics, the policy should be reviewed again.
