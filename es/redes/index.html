03

Proyectos y laboratorios destacados

Estos trabajos muestran cómo aplico los conceptos en entornos reproducibles. Incluyen diseño, configuración, pruebas, fallas controladas, evidencias y documentación técnica.

P01 / SDN

Arquitectura SDN con Faucet, Gauge y observabilidad

  • Open vSwitch
  • Faucet
  • Gauge
  • Prometheus
  • Grafana
  • Docker

Diseñé y documenté una topología SDN con VLAN 100, 200, 300 y 600, múltiples switches lógicos, stacking y rutas principal/respaldo. Integré telemetría con Gauge, Prometheus y Grafana y desarrollé un visualizador SVG con actualización automática para observar la topología y estados.

P02 / IAC

Gestión declarativa de routing con FRR y OSPF

  • FRRouting
  • Docker
  • OSPF
  • Python
  • Source of Truth

Construí un laboratorio con routers FRR en contenedores, configuración OSPF, costos y temporizadores controlados. Implementé detección de configuration drift, reconciliación e intent assurance para validar el camino principal y la ruta de respaldo.

P03 / KPI

Evaluación de desempeño y disponibilidad de red

  • Debian 12
  • iperf3
  • ping
  • tc/netem
  • Proxmox

Implementé un entorno cliente/servidor en máquinas virtuales Debian para medir latencia, pérdida, throughput y comportamiento bajo degradación controlada. Documenté línea base, incidencias de direccionamiento y evidencias técnicas para análisis de KPIs.

P04 / STORAGE

Almacenamiento de red para contenedores

  • TrueNAS
  • NFS
  • iSCSI
  • Docker
  • Nginx
  • MySQL

Integré una VM Docker con almacenamiento TrueNAS mediante NFS e iSCSI. Monté volúmenes persistentes, validé sesiones iSCSI y desplegué servicios Nginx y MySQL utilizando almacenamiento remoto.

P05 / WIN

Infraestructura Windows Server y servicios

  • Active Directory
  • DNS/DHCP
  • RRAS
  • IIS
  • FTP

Trabajé con un entorno de dominio Windows Server, controladores de dominio, servicios de resolución y direccionamiento, RRAS y publicación de servicios IIS/FTP, documentando configuración y validaciones.

P06 / DOCKER

Servicios y redes Docker con persistencia

  • Docker bridge
  • Volumes
  • Redis
  • DokuWiki
  • Nginx
  • MariaDB

He construido varios laboratorios de contenedores con redes aisladas, servicios web y base de datos, persistencia, health checks y pruebas de conectividad entre servicios, incluyendo un portal DokuWiki con Redis y despliegues Nginx/MariaDB.
