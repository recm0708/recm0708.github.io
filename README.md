# Portafolio profesional de Rubén Cañizares

Repositorio principal de mi sitio personal y portafolio profesional publicado con GitHub Pages.

**Sitio:** https://recm0708.github.io/

## Objetivo

Este repositorio reúne mi presencia profesional en línea, incluyendo:

- página personal y presentación profesional;
- perfiles de Currículum Vitae por área;
- proyectos técnicos y de software;
- trayectoria, formación y experiencia;
- información personal seleccionada para el portafolio;
- redes sociales y plataformas profesionales;
- futuras credenciales, certificados y documentos PDF.

## Perfiles de Currículum Vitae

El sitio mantiene tres perfiles profesionales distintos:

1. **Eléctrica y Automatización**
2. **Redes Informáticas e Infraestructura**
3. **Perfil General Multidisciplinario**

Las versiones web son amplias y pueden incluir contexto, proyectos, herramientas y experiencia complementaria. Los PDF ATS se mantendrán como documentos separados y más concisos.

## Idiomas

El portal dispone de contenido en español e inglés. La documentación interna del repositorio, comentarios de código y notas de mantenimiento se redactan principalmente en español.

## Apariencia

El tema claro u oscuro utiliza una única preferencia global almacenada en `localStorage` bajo la clave:

```text
portfolio-theme
```

La selección realizada en cualquier página se conserva al navegar por el resto del portal y se sincroniza también entre pestañas abiertas del mismo sitio.

## Redes sociales

La portada concentra perfiles oficiales en una sección compacta. LinkedIn y GitHub permanecen destacados como canales profesionales principales; las demás plataformas se organizan por categoría y alfabéticamente dentro de cada grupo.

## Convenciones de mantenimiento

- Comentarios del código en español cuando sean documentación para mantenimiento.
- Identificadores técnicos, propiedades CSS, APIs y nombres propios de tecnologías se mantienen en su forma técnica original.
- Mensajes de commit preferentemente en español y con una descripción clara del cambio.
- Evitar código huérfano o archivos heredados que ya no formen parte del diseño vigente.
- No presentar el portal como ejercicio académico, demostración o sitio educativo: es un portafolio personal y profesional.
- No publicar información personal sensible que no aporte al objetivo profesional del sitio.
