# Insignias públicas / Public badges

Esta carpeta contiene únicamente insignias digitales destinadas a visualización pública en el sitio profesional.

## Permitido
- badges oficiales;
- insignias públicas;
- PNG, SVG o WebP optimizados para web;
- archivos visuales emitidos por plataformas o instituciones cuando su publicación sea apropiada.

## No permitido
- certificados PDF;
- diplomas;
- cédula;
- antecedentes;
- licencia;
- idoneidad;
- cartas de referencia;
- archivos con números de identificación u otros datos personales sensibles.

## Organización
Las subcarpetas por emisor o plataforma se crearán únicamente cuando existan archivos reales que lo justifiquen.

## Nombres
Usar nombres descriptivos, por ejemplo:

`cisco__ccna__badge.svg`

`microsoft__learn__badge.png`

Cuando exista una URL oficial de verificación, conservarla en la documentación o metadata correspondiente del sitio.
